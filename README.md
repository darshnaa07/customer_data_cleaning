# customer_data_cleaning
Customer data cleaning and quality -checking project using Google sheets .
Customer Data Cleaning Project

📊 Project Overview

This project demonstrates the cleaning and organization of a fictional customer dataset using Google Sheets.

The purpose of the project is to identify common data-quality issues and prepare the customer information for further use and analysis.

📁 Dataset

The dataset contains 30 fictional customer records with information including:

- Customer ID
- Customer Name
- E-mail
- Phone Number
- City
- Order Amount

🔧 Data Cleaning Performed

The project includes checks for:

- Missing values
- Duplicate customer records
- Inconsistent data entries
- Customer information completeness
- Data quality and validity

The raw data was reviewed and organized into a separate clean-data sheet.

🛠️ Tools Used

- Google Sheets
- Spreadsheet formulas
- Data validation
- Basic data-cleaning techniques

🎯 Skills Demonstrated

- Data entry
- Data cleaning
- Duplicate checking
- Missing-value checking
- Data validation
- Spreadsheet organization
- Basic spreadsheet formulas

📌 Project Type

Personal portfolio project

All customer records are fictional and created for practice purposes. No real customer data was used.

📂 Project Structure

- "Raw Data" — Original fictional customer dataset
- "Clean Data" — Cleaned and validated dataset
- "Summary" — Basic summary of the cleaned data
